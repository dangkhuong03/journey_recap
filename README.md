# Day 27 — Journey Recap / Codex Project Pack

This folder is a ready-to-use instruction pack for OpenAI Codex.

## What to do
1. Put this folder at the root of the project/repository you want Codex to work in, or open this folder directly as the project.
2. Start Codex in that directory.
3. Open `prompts/CODEX_TASK.md` and paste its contents into Codex.
4. Ask Codex to use the local skills in `skills/` if your environment does not auto-discover them.

## Important files
- `AGENTS.md`: persistent Codex instructions and strict scope rules
- `docs/02_JOURNEY_SOURCE.md`: finalized source story; preserved as the content source of truth
- `docs/03_STORY_ARCHITECTURE.md`: revised four-week-first narrative structure
- `docs/04_ACCEPTANCE_CRITERIA.md`: submit-ready audit rubric aligned to the original Day 27 brief
- `docs/05_CONTENT_AND_DESIGN_RULES.md`: rules preventing scope drift, fake metrics, and challenge-gallery design
- `skills/*/SKILL.md`: project-specific reusable Codex skills
- `prompts/CODEX_TASK.md`: the main build prompt

## Key revision after audit
The pack now treats:
- **AI20K / pre-internship background as prologue**
- **the past four internship weeks as the main story**
- **what happened / learned / achieved / evolved as four explicit requirements**
- **mentor outcome misalignment as the main turning point**
- **Before vs Now as the visual climax**
- **Human Evaluation × Development as a future direction only**

There is intentionally **no requirement to select 5–8 challenges or build a challenge-by-challenge portfolio**.

## Intended output
A polished responsive infographic-style landing page for Day 27 that prioritizes four-week visual storytelling, honest achievement framing, clear hierarchy, evidence of growth, and human-centered AI/product thinking.
