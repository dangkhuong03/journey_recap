## How these references were translated into this project
- storyboard before decoration
- guide attention deliberately
- reduce clutter
- turn relationships and change into visuals
- use visuals as communication, not ornament
- build a portfolio/journey narrative people can scan
- package reusable Codex behavior into small, single-purpose skills
