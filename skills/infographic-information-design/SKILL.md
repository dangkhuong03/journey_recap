# Infographic / Information Design Skill

## Goal
Turn information into visual relationships that are faster to understand than paragraphs.

## Choose visual form by information type
- chronology/progression → timeline or path
- transformation → before/after or morph
- process → flow diagram
- learning cycle → loop
- relationships → network/map
- categories → grouped system map
- real quantities → counters/charts only when data exists
- tradeoff/contrast → paired comparison

## Rules
1. Every visual must communicate a relationship, sequence, contrast, quantity, or hierarchy.
2. Do not create charts from invented numbers.
3. Do not use pie/bar/radar charts just to look like an infographic.
4. Prefer direct labeling over legends when possible.
5. Reduce clutter and secondary marks.
6. Use one visual emphasis at a time.
7. Encode meaning consistently across the page.
8. Make the visual interpretable without a long explanatory paragraph.
