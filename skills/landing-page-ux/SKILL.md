# Landing Page UX Skill

## Goal
Make a long-form visual story understandable both to scanners and deep readers.

## Hierarchy rules
1. Every viewport should have a dominant focal point.
2. Headline, visual, supporting copy must have obvious priority.
3. Use scale, contrast, spacing, and position intentionally.
4. Avoid sections where every element has equal visual weight.
5. Keep body copy narrow enough for comfortable reading.

## Scan test
A reviewer who reads only:
- hero
- section headlines
- diagrams
- large callouts
- before/after labels
must still understand the main transformation.

## Section rhythm
Alternate between:
- immersive statement
- compact evidence
- diagram
- reflection
- comparison

Avoid repetitive card grids.

## Responsive rules
- preserve the narrative order on mobile
- diagrams must reflow rather than simply shrink into illegibility
- no horizontal overflow
- touch targets remain usable
- text remains readable without zoom

## Accessibility
- semantic landmarks and headings
- keyboard-accessible interaction
- visible focus states
- sufficient contrast
- reduced-motion support
